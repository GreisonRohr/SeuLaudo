Criar perfil

Você pode ter um perfil para você e outros para familiares (por exemplo, filhos ou pais). Sexo e data de nascimento ajudam a escolher a faixa de referência correta.

Uso dos seus dados de saúde (LGPD)
  • Os laudos que você enviar são dados de saúde, considerados dados sensíveis pela LGPD.
  • Eles ficam guardados neste serviço apenas para mostrar a interpretação e a evolução dos seus exames.
  • Para ler e explicar o laudo, o documento é enviado à API do Claude (Anthropic), sem o seu nome no pedido de interpretação.
  • Você pode excluir um laudo ou o perfil inteiro, com todos os dados, a qualquer momento.
  • A interpretação é educativa: não é diagnóstico e não substitui o seu médico.
